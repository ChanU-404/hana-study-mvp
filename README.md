# Hana Study MVP

학습 인증, 포인트, 캐릭터와 채팅 화면을 구현한 Vite 기반 프런트엔드 프로토타입입니다.

## 실행

Node.js와 npm을 준비하고 프로젝트 폴더에서 실행합니다.

```sh
npm ci
npm run dev
```

배포용 빌드: `npm run build`.

## 구성과 참고

주요 구현은 `main.js`, 스타일은 `style.css`, 이미지는 `public/assets/`에 있습니다. 사진 인증의 AI 분석 표시는 데모이며, 현재 코드는 동일 이미지의 중복 여부를 비교합니다. 실제 AI 판별 서비스가 연결된 것은 아닙니다.

환경 설정과 인증 정보, 설치된 의존성 및 로컬 생성물은 저장소에서 제외합니다.
